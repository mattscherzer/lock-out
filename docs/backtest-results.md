# Backtest Results: Baselines

Generated by `uv run python src/models/backtest.py data/raw/fahrraddiebstahl_2026-10-26.csv` from `fahrraddiebstahl_2026-10-26.csv` (not in Git), with reports up to 24 Oct 2026. Re-running it on the same file gives the same numbers. With the 14-day lag cutoff, this file counts thefts that ended up to 10 Oct 2026, which covers both folds. Reports keep arriving after the cutoff, so a newer file can shift the numbers slightly; compare models on the same file.

## Method

- Two test periods (folds): 1 Apr to 30 Jun 2026 and 1 Jul to 29 Sep 2026.
- Each baseline learns from the 12 months before its fold and scales that count to the fold's length.
- Citywide share: the same expected count for every area (the city average). It ranks nothing, so its Spearman correlation is n/a.
- Raw area history: each area's own count. An area with no thefts in the history counts as 0.5, because the deviance needs a prediction above 0.
- A theft belongs to the period in which its window ended, as in the cleaning pipeline.
- Lower mean Poisson deviance is better; a Spearman correlation closer to 1 means the areas are ranked more like the actual counts.
